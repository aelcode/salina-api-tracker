# Salina API Tracker

This repository tracks the endpoints, status, and issues related to the Salina API, specifically for the staging environment at [https://api-staging.salina.app/salina_v1/docs](https://api-staging.salina.app/salina_v1/docs).

## Purpose

The purpose of this tracker is to:
- Document all available API endpoints
- Track the status of each endpoint (working, issues, deprecated)
- Provide a centralized place to report and track issues
- Maintain historical records of API changes

## How to Use This Tracker

1. View current API endpoints and their status in [API-ENDPOINTS.md](API-ENDPOINTS.md)
2. To report an issue with an endpoint, create a new issue using the issue template
3. To suggest a new endpoint or feature, create a new issue with the "enhancement" label

## Updating Process

This tracker is updated:
- When new endpoints are added to the API
- When existing endpoints are modified or deprecated
- When issues are discovered or resolved
- On a regular schedule (e.g., monthly) to verify all endpoints are still functioning as expected

## Repository Structure

- `README.md` - This file, containing an overview and instructions
- `API-ENDPOINTS.md` - Comprehensive list of all API endpoints and their status
- `.github/ISSUE_TEMPLATE/` - Templates for reporting issues with specific endpoints
